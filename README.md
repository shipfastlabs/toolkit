# Toolkit

Reusable AI tools for the [Laravel AI SDK](https://github.com/laravel/ai). Each tool is its own small package, so you
install only the ones your agents use.

> Requires PHP 8.4+ and `laravel/ai`.

## Documentation

Installation, the tool catalog, and per-tool guides live on the documentation site:

### [toolkit.shipfastlabs.com](https://toolkit.shipfastlabs.com)

## Contributing

This repository is the development monorepo; each `src/<Tool>/` is split into its own read-only package on Packagist.
To add a tool or cut a release, see [CONTRIBUTING.md](CONTRIBUTING.md).
